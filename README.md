### API real de sismos
- Integración con la API oficial del USGS.
- Consulta de los 10 sismos más recientes de América Latina, sin datos simulados.
- Actualización automática de los eventos.
- Sincronización de los sismos en el mapa general, la lista y los mapas de detalle.
- Corrección del cálculo de fechas y tiempo transcurrido usando las marcas de tiempo originales de la API y la zona horaria de Perú.
